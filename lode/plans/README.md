# Plans

Plans for this repository are **GitHub issues** on `zoolutions/daisyui`. That is
the default the local `/plan` command already used, and it is what `/lode:plan`
should keep using: an issue number feeds straight into the implementation
workflow, and the plan and the work that closes it stay in one place.

`/lode:plan --file` writes here instead — `lode/plans/YYYY-MM-DD-<slug>.md` —
when a plan is too long or too speculative for an issue, or when it needs to be
reviewed alongside the code in a PR.

There are no plan files in the tree today, and no `docs/plans/` directory: every
change so far arrived as an issue or straight as a PR.
